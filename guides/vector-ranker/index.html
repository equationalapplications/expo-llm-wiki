Pluggable vector search

By default the engine scores vectors in JavaScript. That’s fine for thousands of facts per entity. For larger corpora, plug in an approximate-nearest-neighbour index through VectorRanker. The engine still handles embedding validation, hybrid blending, and row hydration.

Example: sqlite-vec

Section titled “Example: sqlite-vec”

The SQLite embedding_blob column stays the source of truth. It’s written before the hook is called.

When the ranker fails

Section titled “When the ranker fails”
Policy Behavior Choose it for
'js-cosine' (default) Score in-process, the same as having no ranker Availability
'keyword' Keyword results only Fast degradation
'empty' No facts for this read (tasks and events still load) Strict consistency
'throw' Reject the read() Failing fast

Rules for adapter authors

Section titled “Rules for adapter authors”
  • Parameterize everything. Never concatenate entityId, factId, or candidateIds into SQL.
  • Filter by entityId in every query, to prevent cross-tenant leaks.
  • Scrub credentials from errors. The engine also sanitizes them by default (sanitizeRankerErrors: true).
  • Cap limit and candidateIds.length, and don’t keep references to vector after the call returns.
  • If onEmbeddingPersisted is eventually consistent (for example a remote index), document the lag. Reads may miss new facts until the index catches up.
  • If onEmbeddingPersisted throws while a fact is written or imported, the engine reports hook_failed with the fact id and carries on, so your index can miss that fact. Reconcile from the diagnostic. (Removals are different: a failed removal stays owed and is retried.)

Deletes must reach your index

When a fact is deleted, the engine records it and keeps calling onEmbeddingPersisted with vector: null until your hook resolves once for that id. Make that call idempotent, and don’t resolve without removing. forget() throws WikiExternalDeletionError if an id isn’t confirmed; runPrune() keeps unconfirmed rows. See Deleting data.

Hybrid blending still applies on top of ranker scores when hybridWeight is set.
