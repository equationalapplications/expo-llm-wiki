## Why Core LLM Wiki?

<CardGrid>
  <Card title="Bring your own inference" icon="puzzle">
    You give it one `generateText` function. It builds the prompts, parses the JSON, and writes to
    the database. It works with OpenAI, Gemini, Claude, or a local model.
  </Card>
  <Card title="Just SQLite" icon="seti:db">
    Facts, vectors, and graph edges all live in tables in your database, with a
    `llm_wiki_` prefix by default. You don't run a vector database or Neo4j.
  </Card>
  <Card title="Offline first" icon="rocket">
    Keyword search runs in-process. Semantic search turns on when you provide `embed()`, and
    falls back to keyword search when the network is down.
  </Card>
  <Card title="GraphRAG built in" icon="random">
    Optional ontologies make the model emit typed edges. `traverseGraph()` then walks them
    with a single recursive SQL query.
  </Card>
</CardGrid>

## Pick your platform

<Tabs syncKey="platform">
  <TabItem label="Expo / React Native">
    ```bash
    npx expo install expo-sqlite expo-crypto
    npm install @equationalapplications/expo-llm-wiki
    ```
    The SQLite adapter, secure ID generation, and React hooks are already wired up.
    [Expo quickstart →](/expo-llm-wiki/start/quickstart-expo/)
  </TabItem>
  <TabItem label="React (web)">
    ```bash
    npm install @equationalapplications/react-llm-wiki sql.js
    ```
    Runs entirely in the browser on SQLite compiled to WebAssembly.
    [React quickstart →](/expo-llm-wiki/start/quickstart-react/)
  </TabItem>
  <TabItem label="Node.js">
    ```bash
    npm install @equationalapplications/core-llm-wiki better-sqlite3
    ```
    Use it on a backend or in a worker, with any SQLite driver.
    [Node.js quickstart →](/expo-llm-wiki/start/quickstart-node/)
  </TabItem>
</Tabs>

## Three lines to memory

```ts
await wiki.write('user-123', { event_type: 'observation', summary: 'Loves hiking on weekends.' });
const memory = await wiki.read('user-123', 'what should we do on Saturday?');
const context = formatContext(memory); // → paste into your system prompt
```
