Why Core LLM Wiki?

Section titled “Why Core LLM Wiki?”

Bring your own inference

You give it one generateText function. It builds the prompts, parses the JSON, and writes to the database. It works with OpenAI, Gemini, Claude, or a local model.

Just SQLite

Facts, vectors, and graph edges all live in tables in your database, with a llm_wiki_ prefix by default. You don’t run a vector database or Neo4j.

Offline first

Keyword search runs in-process. Semantic search turns on when you provide embed(), and falls back to keyword search when the network is down.

GraphRAG built in

Optional ontologies make the model emit typed edges. traverseGraph() then walks them with a single recursive SQL query.
